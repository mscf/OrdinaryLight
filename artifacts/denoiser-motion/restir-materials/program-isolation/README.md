# Unused material program isolates the primary shader

All visible materials remain custom diffuse/mirror. The diagnostic wrapper
appends `builtin_material` only to shader generation, leaving the scene program
tuple and packed material IDs unchanged. Existing IDs 0 and 1 retain their
meaning; the added program has ID 2 and no scene material selects it.

| Appended program location | Completed frames | Result |
| --- | --- | --- |
| Neither shader (control) | 4 | Device lost |
| Both shaders | 121 | Clean exit |
| Primary only | 123 | Clean exit |
| Secondary only | 4 | Device lost |

The captured GLSL diffs add only the built-in evaluation function and dispatch
case for ID 2. Binary hashes confirm the secondary-only run retains the original
primary binary and the primary-only run retains the original secondary binary.
All eight captured SPIR-V binaries pass `spirv-val --target-env vulkan1.2`.
This structural validation does not prove runtime memory accesses are valid.

Reproduce from the repository root on the X11/Vulkan desktop, with `MODE` and
`MATERIALS` unset:

```bash
QT_QPA_PLATFORM=xcb PYTHONPATH=. EXTRA_PROGRAM=builtin EXTRA_SHADER=wavefront_primary.comp SHADER_DUMP=/tmp/restir-extra-primary .venv/bin/python artifacts/denoiser-motion/restir-materials/check_materials.py
```

Use `EXTRA_SHADER=wavefront_shade_candidate.glsl` for secondary only; omit
`EXTRA_SHADER` for both. Omit `EXTRA_PROGRAM` for the original control.
The failing controls intentionally reproduce GPU device loss.

This localizes the observed sensitivity to the generated primary shader, rather
than requiring a change in visible scattering or the secondary shader. It does
not distinguish compiler behavior, latent undefined behavior, or a timing change
masking a resource synchronization problem. No production workaround based on
an unused shader branch is proposed. The scene-specific ReSTIR-off setting stays.

branch and compare reduced primary variants, preserving visible material behavior.
The source diffs, run logs and binary hashes are retained here; full temporary
shader dumps are under `/tmp/restir-*` and can be regenerated by the harness.
