OrdinaryLight 0.4.0 completes the migration of OrdinaryLight-authored shader algorithms to typed OrdinaryShade, including the raster feature viewer's GI paths, transport, custom materials, texture and light sampling, volumes, and portable WebGPU rendering.

- Add source-generation and authorship checks to prevent handwritten shader logic from returning.
- Include the shared-primary ReSTIR path, command-history limits, lifecycle diagnostics, and stable-width performance display developed during this work.
- Require OrdinaryShade 0.1.0a5; remove the temporary compiler patch and pin CI to the released compiler commit.
- Ship regenerated SPIR-V, source generators, and both wheel and source distributions.

Validation: 729 OrdinaryLight tests and 106 compiler tests passed, along with transport, box, persistent-query, camera-material, and Vulkan/WebGPU image checks. All 470 packaged shader outputs were accounted for. Rough reflections remained comparable at 30.8 ms versus 31.0 ms for the repeated original reference.

Known limitations: upstream FSR remains temporarily deferred. The two multiple-scattering GI implementations have a pre-existing cross-path discrepancy; each migrated implementation matches its original output exactly. See docs/shader_migration.md for details.

Install the OrdinaryShade 0.1.0a5 wheel from https://github.com/mscf/OrdinaryShade/releases/tag/v0.1.0a5 alongside this release's wheel. These workflows publish GitHub assets, not PyPI packages.
